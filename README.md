إضافة وبوابة دفع إلكتروني رسمية ومحدثة لربط متجر **WooCommerce** بخدمة **إدفع لي (Edfali)** التابعة لـ **مصرف التجارة والتنمية (BCD) - ليبيا 🇱🇾**.

تم تطوير وتحديث هذه الإضافة وإعادة بنائها بالكامل بنظام **AJAX Seamless Checkout** وواجهات منبثقة عصرية لتوفير أسرع وأسهل تجربة شراء إلكتروني في ليبيا.

---

## 🌟 مميزات الإضافة

- ⚡ **دفع فوري بالـ AJAX بدون مغادرة المتجر:** تظهر للمشتري نافذة منبثقة فاخرة وعصرية لإدخال رمز الـ SMS دون إعادة توجيه لصفحات خارجية.
- 📱 **إدخال OTP ذكي وسلس:** حقول ذكية مكونة من 4 خانات تنتقل تلقائياً وتدعم ميزة اللصق المباشر لكود الرسالة.
- 🔄 **أحدث إصدار من Web Service API (2026):** متوافق كلياً مع `NewEdfali.asmx?WSDL` ومعاملات `DoPTrans` و `OnlineConfTrans`.
- 🛡️ **معالجة دقيقة لرسائل وأكواد الأخطاء:** ترجمة الردود البنكية (`ACC`, `Limit`, `PW`, `Bal`) إلى رسائل واضحة ومطابقة للمعايير المصرفية.
- 🧪 **وضع المحاكاة التجريبي (Sandbox Mode):** إمكانية اختبار تجربة الدفع وتأكيد الطلبات حتى في أوقات صيانة خوادم المصرف.
- 📱 **متجاوب 100% مع الهواتف الذكية وتطبيقات الويب.**

## 🛠️ متطلبات التشغيل

1. **WordPress:** الإصدار 5.8 أو أحدث.
2. **WooCommerce:** الإصدار 5.0 أو أحدث.
3. **PHP:** الإصدار 7.4 أو 8.0 أو 8.1 أو 8.2 أو 8.3 مع تفعيل إضافة `ext-soap` و `ext-curl`.
4. **حساب تاجر في خدمة إدفع لي:** (رقم الهاتف المعتمد + الرقم السري PIN المزود من المصرف).

## 📥 طريقة التثبيت

1. حمّل الإضافة بصيغة ملف مضغوط `woocommerce-edfali-payment-gateway.zip` من قسم [Releases](../../releases).
2. من لوحة تحكم ووردبريس، اذهب إلى: **إضافات ⬅️ أضف جديدة ⬅️ رفع إضافة**.
3. اختر الملف المضغوط واضغط **التنصيب الآن** ثم **تفعيل الإضافة**.
4. انتقل إلى: **ووكومرس ⬅️ الإعدادات ⬅️ المدفوعات ⬅️ إدفع لي (Edfali)**:
   - ضع علامة على **تفعيل وسيلة الدفع**.
   - أدخل **رقم هاتف المتجر (Merchant Mobile)** (9 أرقام تبدأ بـ 9 مثال: `9xxxxxxxx`).
   - أدخل **الرقم السري للمتجر (PIN)** المزود من المصرف.
   - اضغط **حفظ التغييرات**.
